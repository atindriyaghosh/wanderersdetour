This is the first post on Wanderer's Detour. If you're reading this, the blog is up and running.

## How this works

Every post is a Markdown file inside the `_posts/` directory. The filename follows the format:

```
YYYY-MM-DD-title-of-the-post.md
```

Each file starts with **front matter** — a small YAML block between `---` lines:

```yaml
---
layout: post
title: "Your Post Title"
date: 2026-02-14
---
```

Everything below the front matter is your post content, written in standard Markdown.

## Writing a new post

1. Create a new `.md` file in `_posts/`
2. Add the front matter at the top
3. Write your content in Markdown
4. Build the site with `jekyll build` or preview with `jekyll serve`

That's it. No databases, no CMS, just text files.
